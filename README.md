# Annapoorna

Corporate website for Annapoorna Enterprises.

## Development

```bash
cd app
npm install
npm run dev
```

## Production build

```bash
cd app
npm run build
```

The Vite app is in `app/`. GitHub Pages deployment uses the workflow in `.github/workflows/deploy.yml`.

## GitHub Pages setup

In the repository settings, set the GitHub Pages source to **GitHub Actions**.
